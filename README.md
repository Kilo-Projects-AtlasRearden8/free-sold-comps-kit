# Free Sold-Comps Kit

Free printable tools for resale price research (eBay, Amazon, Poshmark, and more). No account, no sign-up, no tracking. Open the HTML files in any browser and print.

**Credit:** Built and published by **Asdale Dynamics, LLC** (Indiana). © 2026 Asdale Dynamics, LLC.

## What's inside

| Tool | File | What it does |
|------|------|--------------|
| Sold-comps worksheet | `sold-comps.html` | Record recently sold comparable listings, then auto-computes average, median, min, max, and a suggested price. |
| Condition-grading guide | `condition-grading.html` | Plain-English condition tiers (Like New through Poor) with pricing expectations and a disclosure checklist. |
| Fee estimator | `fee-estimator.html` | Estimates eBay and Amazon fees, shipping, and item cost to show net profit and margin before you list. |
| Price-tracking log | `price-tracking.html` | Log items you list and sell over time, with sell-through rate and average days on market. |

## How to use

1. Open any `.html` file in your browser (Chrome, Firefox, Safari, Edge).
2. Fill in the fields. Totals compute automatically.
3. Press `Ctrl+P` (or `Cmd+P`) to print. Print-only styles hide buttons and controls so the paper copy is clean.
4. Works entirely offline — no account, no internet, no personal data leaves your computer.
