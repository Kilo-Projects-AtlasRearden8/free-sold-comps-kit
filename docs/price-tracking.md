# Price-Tracking Log

Log items you list and sell over time. See your sell-through rate, average sale price, and average days on market.

Printable. No account needed. Works offline. © 2026 Asdale Dynamics, LLC.

## How to use

1. Open `price-tracking.html` in any browser.
2. Add one row per item you list.
3. Update the **status** (Listed / Sold / Relisted / Ended) and **sold price** when the item sells.
4. **Days listed**: how long from listing to sale (or to today if still listed).
5. Stats compute automatically:
   - Sell-through rate = sold ÷ listed
   - Average sale price uses sold items only
   - Average days listed across items with a days value
6. Review monthly to see which categories, conditions, and price points move fastest.
7. Print this page (Ctrl+P / Cmd+P) for your records.

## Fields

| Field | What to enter |
|-------|---------------|
| # | Auto-numbered |
| Item | Title of the item you're listing |
| Marketplace | eBay, Amazon, Poshmark, Mercari, local, etc. |
| Condition | Condition tier |
| List price | What you listed it for |
| Sold price | What it actually sold for (leave blank until sold) |
| Status | Listed, Sold, Relisted, Ended |
| Date listed | Date you listed it |
| Days listed | Days from listing to sale (or today if still listed) |
| Notes | Shipping terms, flaws, relist reason, etc. |
